# 宣传视频稿（定稿 2026-10-16）

配音：Edge TTS，中文配音 + 中文字幕，无 BGM，不刻意玩梗。

## 横屏版（B 站 / YouTube，1920×1080，约 2 分钟）

| # | 画面 | 旁白 |
|---|---|---|
| 1 开场 | 主页 → 进入对局，开局棋盘 | 这是象棋大乱斗，一款在浏览器里就能玩的中国象棋变体。规则和象棋基本一样，但多了一样东西：锦囊。 |
| 2 锦囊机制 | 三选一界面弹出 → 选中 → 双方锦囊同时揭晓；白银 / 黄金 / 棱彩三种边框依次闪过 | 对局的第一、五、十、十六回合，双方各自从三个随机锦囊里挑一个，改写自己棋子的规则。锦囊一共二十九个，分白银、黄金、棱彩三档，越往后品质越高。 |
| 3 锦囊示例 | 四个镜头各 4–5 秒，左上角标锦囊名：天马行空、纵横天下、火烧连营、借尸还魂 | 比如：马不再被蹩腿，车可以斜着走，炮吃子后连带烧掉周围的敌子，被吃掉的车马炮还能在原位复活。每一局拿到的锦囊不同，打法也不一样。 |
| 4 胜负与护盾 | 护盾挡下吃子 → 将帅出现红圈 → 吃将，胜利结算 | 胜负规则也有变化：吃掉对方的将帅才算获胜。有些锦囊会给棋子加上护盾，挡下一次吃子。将帅有危险时，界面会用红圈提醒。 |
| 5 对战玩家 | 菜单 → 创建房间（房间号、邀请链接）→ 左右两个窗口同步对局 → 切到同屏对战 | 对战玩家有两种方式。联机对战：创建房间，把链接发给朋友，打开就能下，不用注册。同屏对战：一台设备，两个人轮流走棋。 |
| 6 规则 AI | 挑战 AI 设置页（难度、性格）→ 对局中点「💡 提示」出现金色箭头 | 挑战 AI 模式里，可以和规则 AI 对战，有四档难度和三种性格，支持悔棋，卡住时还可以让 AI 给出走法提示。 |
| 7 挑战大模型 | 设置页模型列表（密钥打码）→ 对局中大模型点评气泡 → 点「🧠 偷看思考」展开 | 也可以接入你自己的大模型，比如 DeepSeek、通义、GPT、Claude。你每走一步，它会先点评你这步棋，再落子。想知道它在想什么，可以点开偷看思考。API 密钥只保存在你自己的浏览器里。 |
| 8 模型斗蛐蛐 | 斗蛐蛐设置页 → 观战，双方发言气泡 → 显示双方思考 → 结算页 | 模型斗蛐蛐模式，让两个大模型互相对战，你来观战。双方看不到对方的思考，可以边下边发言，打开对喷模式后还能互相回嘴。 |
| 9 回放 | 结算页「查看回放」→ 逐步播放 → 对局记录列表 → 复制分享链接 | 每局结束后都可以查看回放。最近的对局会自动保存在本机，也可以用一条链接分享给别人。 |
| 10 结尾 | 主页，屏幕中央显示网址 wervex.github.io/xiangqi-mayhem 和 GitHub 地址 | 象棋大乱斗，电脑和手机都能玩，打开浏览器就能开始。游戏开源免费，链接在简介里。 |

## 竖屏版（抖音，1080×1920，约 40 秒）

手机布局，字幕放中上部。

| # | 画面 | 旁白 |
|---|---|---|
| 1 | 锦囊揭晓 → 车斜走吃子 | 这是一款每局规则都不一样的象棋。 |
| 2 | 三选一界面 → 快切马不蹩腿、车斜走、棋子复活 | 对局中，双方会多次从三个锦囊里挑一个，改写自己棋子的规则：马不蹩腿、车能斜走、被吃的子还能复活。 |
| 3 | 联机邀请链接 → 规则 AI 对局 → 大模型点评气泡 | 可以和朋友联机，发个链接就能下；可以挑战 AI，也能接入大模型跟你对弈。 |
| 4 | 斗蛐蛐观战，双方气泡 | 还能让两个大模型互相对战，你来观战。 |
| 5 | 主页 + 大号网址 | 象棋大乱斗，打开浏览器就能玩，网址就在屏幕上。 |
