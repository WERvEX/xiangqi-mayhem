# 象棋大乱斗 · Xiangqi Mayhem

> 中国象棋 × 锦囊三选一。每局都不一样的象棋。

**[▶ 在线游玩](https://wervex.github.io/xiangqi-mayhem/)**

## 介绍

象棋大乱斗是一个在浏览器里玩的中国象棋变体，灵感来自英雄联盟的海克斯大乱斗：对局进行中，双方会多次从三个随机「锦囊」里挑一个，改写自己棋子的规则。

马不再蹩腿、车能斜着走、炮能隔两个子打、将帅能和士换位置、被吃的子能复活……每个锦囊都会让局面产生新的变化，每一局的打法都不一样。

- 🎴 **29 个锦囊**，分白银、黄金、棱彩三档
- 🤖 **人机对战**：4 档难度、3 种 AI 性格，可悔棋
- 🧠 **挑战大模型**：接入你自己的大模型（DeepSeek、GLM、通义、GPT、Claude……），它会边下边点评你的棋，还能偷看它在想什么
- 🦗 **模型斗蛐蛐**：两个大模型对战，边下边嘴炮，你来观战，看看哪家模型棋下得好
- 🌐 **联机对战**：创建房间，把链接发给朋友就能对战，不用注册
- 👥 **同屏对战**：一台设备两个人轮流下，可悔棋
- 🎬 **回放分享**：一条链接就能分享整局棋
- 📱 电脑、手机都能玩，不用安装

## 使用

### 直接游玩

打开 **https://wervex.github.io/xiangqi-mayhem/** 即可。主页有三个入口：

- **对战玩家**：联机对战，或者同屏对战（一台设备两个人轮流走棋）
- **挑战 AI**：对手可以选「规则 AI」或「大模型」
  - 规则 AI：选择执红或执黑、难度（入门 / 普通 / 困难 / 大师）和 AI 性格（均衡 / 激进 / 稳健）
  - 大模型：见下文「挑战大模型」
  - 悔棋会连同 AI 的应对、锦囊选择一起撤回到你上一次走棋之前
- **模型斗蛐蛐**：选两个大模型对战，你来观战，见下文「模型斗蛐蛐」

其他功能：

- **自动存档**：人机对战（含大模型）、同屏对战和模型斗蛐蛐会自动保存，刷新或关闭页面后，主页会出现「继续上一局」。对局结束后存档自动删除
- **音效**：落子、吃子、护盾挡下、复活、锦囊揭晓、叫杀提醒等都有音效（全部现场合成，不用下载），对局中点「🔊」可以关闭
- **走法推荐**：人机和同屏对战中，点「💡 提示」让 AI 推荐一步（可选推荐强度），推荐会用金色箭头标在棋盘上；选锦囊时可以点「💡 AI 推荐」。联机对战中不提供
- **回放与对局记录**：
  - 对局结束后可以直接「查看回放」，或者「分享回放」（复制链接、下载回放文件）
  - 最近 20 局会自动保存在本机，主页「对局记录」里可以随时观看、分享
  - 别人分享的链接或文件也在「对局记录」里打开
- **联机对战**：
  1. 点「联机对战」→ 选择执红、执黑或随机 →「创建房间」
  2. 把 6 位房间号或邀请链接发给朋友
  3. 朋友打开链接（或在「加入房间」里输入房间号）即可开始

> **联机小贴士**
> - 联机优先点对点直连；双方网络无法直连时（比如手机流量），会自动经中转服务器转发。连上后状态条会显示「直连」或「经中转」
> - 连不上时，双方都在联机大厅点「网络检测」，可以看出是哪一步出了问题
> - 在微信、QQ 里点链接可能会被拦截，可以复制链接到浏览器打开
> - 断线、刷新页面都会自动重连：客人刷新后直接回到对局；房主刷新后房间会恢复，客人自动连回来。房主关闭页面则房间失效
> - 客人不小心退出了（点了离开、手机返回、关掉页面），用房间号或邀请链接重新加入就能接着下，换页面、换设备都可以
> - 想悔棋可以点「申请悔棋」，对方同意后撤回你的上一步

### 挑战大模型

和你自己接入的大模型下棋。它每步会先点评你的棋，再自己落子，你还可以偷看它在想什么。

**第一次使用（约 2 分钟）**

1. 主页「⚙ 设置」→「添加模型」，在「服务商」里选一个预设（见下表），地址会自动填好
2. 填 API 密钥，点「获取列表」，在列表里搜索、选择模型（获取不到就手动填写模型名）
3. 「思考强度」建议选「关闭」，点「测试连接」，看到「连接成功」就可以保存了
4. 回到主页「挑战 AI」→ 对手选「大模型」→ 选模型、发言人设和辅助等级 → 开始对局

**常见服务商**

| 服务商 | 网页能否直接调用 | 说明 |
|---|---|---|
| DeepSeek、智谱 GLM、通义千问（阿里云百炼） | ✅ | 国内直接可用 |
| OpenAI、Anthropic（Claude）、Google Gemini | ✅ | 需要能访问对应服务 |
| OpenRouter、硅基流动 | ✅ | 一个密钥用多家模型，Kimi 等也可以从这里用 |
| 火山方舟（豆包、方舟 Coding Plan 等）、Kimi 官方 | ❌ | 需要运行本地转发，见下文 |

预设里没有的服务商，选「自定义」，填它的 OpenAI 兼容（或 Anthropic）接口地址即可，大部分服务商都至少支持其中一种。

**对局中**

- 大模型发言显示在棋盘两侧（手机上在双方信息栏旁边），最新的一句在最上面
- **🧠 偷看思考**：显示它最新一步的局面判断、走这步的理由，以及它给自己记的「作战笔记」（策略、接下来的计划、要提防什么）。模型每步都会带着自己的笔记和最近几步的决策继续思考，前后连贯
- **📜 实时思维链**：模型思考时实时显示它正在输出的内容（下一步开始生效）
- 模型想太久时可以点「跳过」，由规则 AI 代走这一步
- 模型回复格式不对会自动重试；仍然失败就由规则 AI（困难）代走，对话框里会写明代走了哪一步和原因
- 密钥错误、额度用完等问题会暂停对局，可以修改模型设置、重试，或者让规则 AI 接管剩下的对局
- 对局结束后点「查看回放」，可以逐步查看模型每一步的发言和思考

**辅助等级**：大模型自己算棋容易漏看杀棋，可以让规则引擎帮它把关

| 等级 | 给模型的信息 | 适合 |
|---|---|---|
| 裸考 | 只给棋盘和合法走法 | 看模型的真实棋力 |
| 基础标注 | 再标出送将、将军、走后会被吃的走法 | |
| 战术检查（默认） | 引擎再往后算几步，标出会被杀、会吃亏的走法；被叫杀时直接告诉模型哪几步能解 | 推荐，下得像样又有模型自己的风格 |
| 引擎推荐 | 再标出引擎推荐的三步，模型主要负责挑选和发言 | 想要更强的对手 |

模型选了一步明显会吃大亏的棋时，会被要求再确认一次。

**思考强度**：思考越多下得越好，但也越慢，部分模型默认深度思考，每步要等几十秒。推荐「**关闭思考 + 战术检查**」：每步几秒，也不容易漏看杀棋。「关闭」会按服务商自动选择对应的参数；如果模型实在关不掉思考，对话框里会提示。

**隐私**：密钥只保存在你自己的浏览器里（也可以选「只在本次打开时有效」），请求由浏览器直接发给模型服务商，不经过任何其他服务器；密钥不会出现在回放和分享链接里。

**本地转发**（火山方舟、Kimi 官方等不允许网页直接调用的服务商）：需要电脑上装有 [Node.js](https://nodejs.org/)（20 或以上）。

```bash
git clone https://github.com/WERvEX/xiangqi-mayhem.git
cd xiangqi-mayhem
npm install
npm run llm-proxy
```

保持这个窗口开着，然后在模型设置的「高级 → 转发地址」里填 `http://127.0.0.1:8787`。转发只在你自己的电脑上运行，只接受本机页面和本站的请求。

### 模型斗蛐蛐

两个大模型对战，边下边嘴炮，你来观战。

**开始一局**

1. 先按上文「挑战大模型」添加至少一个模型
2. 主页「模型斗蛐蛐」：给红黑双方各选模型、发言人设和辅助等级。可以是两个不同的模型，也可以是同一个模型换两种人设自己打自己；点「⇅」交换双方设置
3. 选观战速度（慢 / 中 / 快，即每步至少停留多久），决定双方是否发言、是否打开「对喷模式」，然后开始对局

**怎么玩更有意思**

- **公平对比两个模型**：双方用相同的辅助等级和思考强度，比完再交换红黑打一局
- **看热闹**：打开「对喷模式」，配上「嘴硬棋手」「古风谋士」之类的人设
- **省额度**：关掉「双方每步发言」，请求数大约减半。一局通常 60–150 步，状态栏会实时显示双方各自的 token 用量（输入 / 输出）

**观战中**

- 开局双方先做自我介绍，之后每当对方走了棋就点评一句
- 每个模型只看得到棋盘、双方的走法和公开的锦囊，**看不到对方的思考**；发言默认也互相听不到，打开「对喷模式」后才能听到对方上一句话，但思考仍然完全隔离
- 可以暂停、调速度，用「🧠 显示思考」「📜 实时思维链」看双方在想什么
- 某一方出错时对局暂停，可以修改那一方的设置、重试，或者让规则 AI 接管它
- 对局自动存档，刷新页面后主页会出现「继续上一局」
- 结束后弹出结算：胜负、回合数、双方的 token 用量和结束语，可以直接查看或分享回放（回放文件里有双方的发言和思考）

### 常见问题

- **模型每步都很慢**：把模型设置里的「思考强度」改成「关闭」。如果提示「这个模型关不掉思考」，可以换成 OpenAI 兼容接口试试
- **测试连接失败**：按提示检查密钥、模型名和余额；提示跨域或网络错误的，多半是这家服务商不允许网页直接调用，需要本地转发
- **模型总是被规则 AI 代走**：点开对话框里的说明看原因，常见的是回复被截断（思考太长）或者格式不对，关闭思考通常能解决
- **联机连不上**：见上文「联机小贴士」

## 玩法

### 基本规则

- 棋子走法与中国象棋相同
- **吃掉对方的将（帅）即获胜**。允许送将，界面会提醒：
  - 🔴 红圈：将帅可以被直接吃掉
  - 🟡 黄圈：将帅会被攻击，但有护盾或锦囊挡下（通常要付出代价）
  - 走出送将的一步前会弹出确认
- 将帅在同一直线上且中间无子时，可以「飞将」直接吃掉对方
- 无棋可走判负；同一局面重复三次，或超过 150 回合判和

### 锦囊

- 第 **1、5、10、16** 回合，双方各自从 3 个锦囊中选 1 个。发放轮流在红方、黑方走棋前进行，双方各有两次先用上新锦囊的机会
- 越往后品质越高：白银 → 黄金 → 棱彩。同一次发放中双方的品质相同
- 每局有 1 次刷新选项的机会
- **逆风补偿**：子力落后 5 分以上的一方，本次锦囊品质提升一档
- 双方都选完后锦囊同时揭晓、同时生效，先选的一方不会暴露自己的选择；揭晓后对双方公开，点对方的锦囊可以查看效果

### 护盾

护盾会挡下一次吃子：攻击者原地不动，护盾消失，这一回合也就用掉了。

- 每个子最多 1 层护盾
- 带护盾的子**主动吃子时也会消耗护盾**。护盾擅长防守，但不能让一个子刀枪不入地一路吃下去

## 路线图

长期目标是做成一款**以 PVP 竞技为核心**、带关卡和可解锁内容的独立游戏。按以下顺序推进：

### ✅ 阶段 0 · MVP

- [x] 规则引擎、29 个锦囊、同屏对战、P2P 联机
- [ ] 根据真人试玩反馈继续调整平衡
- [x] 联机断线重连、房主刷新后恢复房间、双方同意后悔棋；自建中转服务器，跨网络也能连上

### ✅ 阶段 1 · 人机对战（基于规则的 AI）

- [x] 搜索 AI：迭代加深、静态搜索、置换表，放在后台线程计算，思考时界面不卡顿
- [x] 4 档难度，3 种性格（均衡、激进、稳健）
- [x] AI 按性格挑选锦囊
- [x] **对局回放与分享**：一局棋由"种子 + 操作序列"完整决定，可以生成链接、下载文件、逐步重播；也是后续大模型对战的基础

### ✅ 阶段 2 · 玩家对战大模型

- [x] 玩家填写自己的大模型 API 密钥，**密钥只保存在本地浏览器，不会上传**，请求由玩家的浏览器直接发给模型服务商
- [x] 大模型每一步：先点评**玩家这一步和当前局势**（不透露自己的打算）→ 隐藏的思考 → 落子
- [x] 走子时把棋盘、双方锦囊和**所有合法走法的编号列表**发给模型，让它只选编号，因此不会走出违规棋；连续出错时由规则 AI 代走并标出
- [x] 支持 Anthropic 接口和 OpenAI 兼容接口（可自定义地址），可自动获取模型列表
- [x] 发言人设、辅助标注开关、回放中查看思考、回放文件保存发言与思考
- [x] 本地转发工具，支持不允许网页直连的服务商（设计见 [docs/LLM-DESIGN.md](docs/LLM-DESIGN.md)）

### ✅ 阶段 3 · 大模型对战大模型（赛博斗蛐蛐）

- [x] 选两个模型对战，实时观看双方的发言、思考和走子
- [x] **双方的思考互相隔离**：每个模型只能看到棋盘和公开信息；发言默认也隔离，可选「对喷模式」让双方互相回嘴
- [x] 暂停、调速度，对局自动存档，可导出回放
- [x] 结构化思考与作战笔记（每步带着自己的策略和计划继续想），实时思维链，结算页面
- [ ] 模型排行榜

### 阶段 4 · 独立游戏化

- **排位 PVP**：账号、匹配、段位与赛季；对局由服务器用同一套规则引擎校验，防止作弊
- **PVP 公平**：排位赛使用统一的锦囊池，解锁内容不影响 PVP 胜负
- **PVE 为辅**：新手教程、残局解谜关卡（经典残局 + 锦囊）、挑战 AI
- **等级与解锁**：棋子皮肤、棋盘、特效等外观，以及 PVE 关卡和成就
- 正式美术与音效；打包为 PC 版（Steam），之后考虑手机版

### 长期研究

- 基于模型的 AI：用自我对弈数据训练局面评估模型，替换手写的评估函数

### 已知风险

- 浏览器直接调用模型 API 需要服务商允许跨域请求（CORS）。不允许的服务商需要用户在本地运行转发，或者通过 OpenRouter 等中转平台使用
- P2P 联机依赖我们自己的中转服务器兜底，服务器到期或带宽不够时需要续费或升级；做排位 PVP 时会改为服务器权威
