# 象棋大乱斗 · Xiangqi Mayhem

中国象棋 × 锦囊三选一。灵感来自英雄联盟海克斯大乱斗：对局中途双方各自从三个锦囊里挑一个，改写棋子规则，每局都不一样。

## 玩法

- 棋子走法与中国象棋相同；**吃掉对方将帅即获胜**（允许送将，界面会提醒）
- 将帅照面时可"飞将"直接吃掉对方
- 第 1 / 10 / 20 回合开始时发放锦囊（白银 / 黄金 / 棱彩），每局可刷新 1 次
- 子力落后较多时，锦囊品质提升一档
- 同一局面重复三次或超过 150 回合判和；无棋可走判负

目前共 15 个锦囊，可在游戏主页的「锦囊图鉴」查看。

## 模式

- **同屏对战**：一台设备轮流下，可悔棋
- **联机对战**：创建房间后把 6 位房间号或邀请链接发给好友。基于 WebRTC 点对点直连（PeerJS），不需要自己的服务器；对方刷新页面可自动重连，结束后双方同意即可交换先后手再来一局

> 联机说明：点对点直连在部分网络下（尤其是手机流量）可能连不上，连同一个 Wi-Fi 最稳定。

## 开发

```bash
npm install
npm run dev      # 本地开发 http://localhost:5173
npm test         # 规则引擎单元测试
npm run build    # 构建到 dist/
```

### 目录结构

```
src/
  engine/        # 纯逻辑规则引擎，不依赖 UI
    types.ts     # 数据类型
    board.ts     # 棋盘、初始局面、工具函数
    movegen.ts   # 走法生成（读取锦囊的规则修改）
    augments.ts  # 全部锦囊定义
    game.ts      # 对局状态机：走子、锦囊发放、胜负判定
  net/           # 联机
    protocol.ts       # 消息格式
    transport.ts      # 传输层接口（可替换为 WebSocket 中转等）
    peerTransport.ts  # PeerJS 实现
    session.ts        # 联机会话：房主权威、断线重连、再来一局
  ui/            # React 界面
```

### 添加一个锦囊

在 `src/engine/augments.ts` 的 `AUGMENT_LIST` 中加一项即可。可用的扩展点：

- `mods`：修改走法规则（如马不蹩腿、炮隔两子）
- `onPick`：选中时立即生效（如加护盾）
- `onAfterMove`：每走一步后触发（如升变、额外行动）
- `onOwnCaptured`：己方棋子被吃时触发（如复活）
- `status`：在界面上显示的计数器

所有随机都由「对局种子 + 用途」哈希得到，联机时双方只需同步操作就能算出一致的结果。
